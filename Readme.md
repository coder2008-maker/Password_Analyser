# 🔐 Password Security Analyzer

A beginner-friendly cybersecurity application that analyzes
password security risks and provides recommendations for
creating stronger passwords.

## Features

- Password length analysis
- Character diversity checking
- Common password detection
- Predictable sequence detection
- Repeated character detection
- Security risk assessment
- Recommendations for improving weak passwords
- Sample test cases
- Passwords are not stored

## Technologies

- Python
- Tkinter

## How to Run

```bash
python password_analyzer.py
